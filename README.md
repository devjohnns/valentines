# 💕 Valentine's Day Interactive Page

A beautiful, interactive Valentine's Day webpage with animations, music, and heartfelt messages.

## 📁 Project Structure

```
valentines/
├── index.html      # Main HTML file
├── style.css       # Stylesheet with animations
├── script.js       # JavaScript for interactivity
├── music.mp3       # Background music
├── photo1.jpg      # Photo: "My Baby Girl"
├── photo2.jpg      # Photo: "My Princess"
├── photo3.jpg      # Photo: "Pookie"
├── photo4.jpg      # Photo: "My Everything"
└── photo5.jpg      # Photo for Bible verse section
```

## ✨ Features

- **Background Music**: Toggle music on/off with the button in top-right corner
- **Floating Hearts**: Continuous heart animations rising from bottom
- **Floating Photos**: 4 photos with captions positioned around the page
- **Interactive Buttons**: 
  - "Yes" button shows thank you message with confetti effect
  - "No" button moves away when you hover over it
- **Love Letter**: Heartfelt romantic paragraphs
- **Apology Message**: Sincere apology before the question
- **Bible Verse**: 1 Corinthians 13:4-7 with photo
- **Beautiful Animations**: Fade-ins, slide-ins, bounces, and floating effects

## 🚀 How to Use

1. Open `index.html` in a web browser
2. Click the music button (🔊) to start the background music
3. Scroll through the page to read the messages
4. Try hovering over the "No" button (it runs away!)
5. Click "Yes" to see the thank you message with heart confetti

## 💻 Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript
- Google Fonts (Playfair Display, Poppins)

## 📝 Notes

- All code is commented for easy understanding
- Responsive design works on different screen sizes
- No external libraries required (pure vanilla JS)
- Music requires user interaction to play (browser policy)
